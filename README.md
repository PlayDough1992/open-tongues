# Open Tongues

Open Tongues exists to protect educational freedom: high-quality language learning should be public, practical, and available to everyone without subscriptions, paywalls, or account lock-in.

## Live Site

Use the project here:

https://playdough1992.github.io/open-tongues/

## Mission

- Keep language education free and accessible worldwide.
- Remove account walls and recurring fees from core learning.
- Build tools that can be hosted cheaply and shared openly.
- Make learning resilient with local-first progress and offline-friendly behavior.

## What Open Tongues Is

- A single-file web app focused on language practice.
- Built to run on GitHub Pages with no backend required.
- Includes core study modes: flashcards, quiz, phrase lab, and advanced phrase construction.
- Starts with English, Spanish, and Mandarin tracks and is designed to expand.

## Why Single File

One file keeps publishing simple, transparent, and durable:

- Easy to fork and remix.
- Easy to mirror and self-host.
- Minimal operational cost.
- No build pipeline required for public deployment.

## Project Structure

- [index.html](index.html): full app UI, learning logic, translation system, and course data.
- [.github/workflows/pages.yml](.github/workflows/pages.yml): GitHub Pages deployment workflow.

## Deploy on GitHub Pages

This repository is already configured for GitHub Pages with Actions.

1. Push to the main branch of your repository.
2. In GitHub, open Settings -> Pages.
3. Set Source to GitHub Actions.
4. Wait for the workflow run to finish.

Site URL pattern:

https://YOUR_USERNAME.github.io/YOUR_REPO/
